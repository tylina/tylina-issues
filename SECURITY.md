# Security Policy / 安全政策

Do not open a public issue for a suspected security vulnerability. Do not include exploit details, private documents, credentials, or personal information in a public discussion.

如果你怀疑存在安全漏洞，请不要创建公开 issue，也不要在公开讨论中附上利用细节、私人文档、凭据或个人信息。

Use [GitHub private vulnerability reporting](https://github.com/tylina/tylina-issues/security/advisories/new) to send the report privately. Include the affected Tylina version, operating system, impact, and the smallest safe reproduction you can provide.

请通过 [GitHub 私密漏洞报告](https://github.com/tylina/tylina-issues/security/advisories/new) 提交，并写明受影响的 Tylina 版本、操作系统、影响范围，以及可以安全提供的最小复现方法。

The repository owner should enable **Settings → Security → Private vulnerability reporting** before publishing this repository.
