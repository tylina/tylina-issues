这里是 Tylina 的公开反馈仓库，用于报告问题、提出功能建议和寻求使用帮助。

Tylina 是专有桌面软件。本仓库不包含 Tylina 应用源码，也不接受应用源码的 Pull Request。

提交前请：

1. 搜索现有 issue，避免重复报告。
2. 写明 Tylina 版本、操作系统与处理器架构。
3. 尽量提供稳定、简短的复现步骤。
4. 删除文档、路径、截图和日志中的机密信息。

不要公开提交密码、访问令牌、私人文档、未公开项目或安全漏洞细节。安全问题请阅读[安全政策](SECURITY.md)，通过 GitHub 私密漏洞报告提交。
