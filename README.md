This is the public feedback repository for Tylina. Use it for bug reports, feature requests, and product questions.

Tylina is proprietary desktop software. This repository does not contain the Tylina application source code and does not accept pull requests for the application itself.

Before filing an issue:

1. Search existing issues to avoid duplicates.
2. Include the Tylina version, operating system, and processor architecture.
3. Provide short, repeatable steps whenever possible.
4. Remove confidential information from documents, paths, screenshots, and logs.

Do not post passwords, access tokens, private documents, unreleased project material, or vulnerability details publicly. For security issues, read the [Security Policy](SECURITY.md) and use GitHub private vulnerability reporting.

- [Request a feature](https://github.com/tylina/tylina-issues/issues/new?template=feature.yml)
- [Ask a product question](https://github.com/tylina/tylina-issues/issues/new?template=question.yml)
