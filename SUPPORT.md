# Support / 使用帮助

Use the [question form](https://github.com/tylina/tylina-issues/issues/new?template=question.yml) for public product questions that are not bug reports.

非问题报告的公开使用疑问，请使用[使用问题表单](https://github.com/tylina/tylina-issues/issues/new?template=question.yml)。

Before posting:

- Check the Help documents included with Tylina.
- Search open and closed issues.
- Include the application version and system information.
- Share a minimal example rather than a private document.

提交前：

- 先查看 Tylina 内置帮助文档；
- 搜索尚未关闭和已经关闭的 issue；
- 写明应用版本与系统信息；
- 使用最小示例，不要上传私人文档。

This is a public repository. Anyone can read submitted issues and attachments. Do not use it for security vulnerabilities or confidential material.

本仓库公开可见，所有人都能阅读 issue 与附件。请勿在这里提交安全漏洞或机密材料。
